## Discord bot that adds buildplates for the minecraft earth vienna server
> [!NOTE]
> In the bot.py change the data to your own in `TOKEN = YOUR OWN BOT TOKEN` and `VIENNA_PATH = r"YOUR PATH TO THE VIENNA SERVER'S ROOTFOLDER"`
> Also install the latest version of [Python](https://www.python.org/downloads/release/python-3142/) and `python -m pip install discord.py`
-
  Commands:
```
!addbuildplate {your playfab id}
```
```
!check {patch found/not found}
```
